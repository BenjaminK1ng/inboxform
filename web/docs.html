1. Create a form

You get a form_id (public, used in your page's action URL) and a key (secret, for reading submissions).

curl -X POST https://YOUR-DEPLOY/api/forms \
  -H 'content-type: application/json' \
  -d '{"name":"Contact", "webhook":"https://example.com/hook", "ai_reply":false}'

{ "form_id": "a1b2c3d4e5f6a7b8", "key": "…", "endpoint": "/f/a1b2c3d4e5f6a7b8", "plan": "free" }

2. Accept submissions

Point any form at the public endpoint. Use _company as a hidden honeypot field.

<form method="post" action="/f/a1b2c3d4e5f6a7b8">
  <input name="email"> <input name="message">
  <input name="_company" style="display:none">
  <button>Send</button>
</form>

Or JSON:

curl -X POST https://YOUR-DEPLOY/f/a1b2c3d4e5f6a7b8 \
  -H 'content-type: application/json' -d '{"email":"a@b.c","message":"hi"}'

3. Read submissions

curl "https://YOUR-DEPLOY/api/submissions?key=YOUR_KEY&formId=a1b2c3d4e5f6a7b8"

4. Webhooks

Set webhook at creation: every submission is POSTed to your URL as JSON, including ai_reply when enabled.

5. AI reply drafts

Create with "ai_reply":true. Each submission returns an ai_reply field — a draft response written by DeepSeek. Pro plan only. Costs fractions of a cent per draft.
